7. REGEX TESTÉES
================

Votre SN_REGEX : r"(?:S/?N)\s*[:\-°]*\s*((?=[\w-]*\d)[\w-]+)"

Tests positifs :
✅ "SN12345" → "12345"
✅ "SN 240" → "240"  
✅ "SN1000_1310" → "1000_1310"
✅ "S/N ABC-123" → "ABC-123"

Tests négatifs :
❌ "document.pdf" → None
❌ "SN" → None (pas de chiffre)
❌ "SNDevice" → None (pas de chiffre)

Votre PROG_REGEX : r"[\w,-]+\.rule"

Tests positifs :
✅ "Elio_Muxis_V1.rule" → "Elio_Muxis_V1.rule"
✅ "Programme-Test.rule" → "Programme-Test.rule"

Tests négatifs :
❌ "programme.txt" → None
❌ "pas de programme" → None
